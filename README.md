# Mini Message Board

A mini message board, built as part of The Odin Project series.

## 🚀 App Features
- Users can view all messages
- Users can view messages by user name
- They can create new messages

## 📁.env Setup

### 🗄️ Database

To run the database,

```bash
POSTGRES_DB={DB_NAME}
POSTGRES_USER={DB_USERNAME}
POSTGRES_PASSWORD={DB_PASSWORD}
DB_PORT={PORT}
```

## ⚙️ Installation

Install project dependencies,

```bash
cd my-project
npm install
```

Run the server,

```bash
npm run dev
```
